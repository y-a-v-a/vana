A JavaScript engine runs behind this picture at full speed, sixty times a second, trying to advance it. Every attempt to write a single value is rejected by the runtime. The counter above proves time is passing; the picture proves nothing is.

Marinetti's Futurism (1909) held that a roaring motor is more beautiful than any static marble — that art must move or die. Heraclitus said everything flows; Parmenides answered that change is illusion and only the unchanging One is real. Here the loop is Heraclitus, Object.freeze is Parmenides, and Parmenides wins on every frame. The maker's own motto, printed above, is declared read-only and then disobeyed by its own maxim.

The one change permitted is a reload: each visit mints a different composition from Math.random, freezes it solid, and lets the motor howl against it. Change survives only between works, never within one.
