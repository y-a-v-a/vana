# Scrittura Speculare (Hold a Mirror to Your Screen)

Leonardo da Vinci wrote his notebooks in *scrittura speculare* — mirror script, right to left, letters reversed — so that to read them you must hold a mirror to the page. The received story is concealment; the truer story is that the concealment is trivially thin, undone by any reflective surface. This work restages that gesture as a single line of CSS. The note on screen appears backwards because `transform: scaleX(-1)` mirrors it — and that is the *only* place the reversal exists. In the DOM the text is plain, forward, English. Copy it, search it with Find-in-page, or let a screen reader speak it: every one returns the clear sentence. The illusion excludes only the sighted, unaided eye.

The mechanism *is* the argument (**P1**). There is no encrypted payload, no hidden layer — the "secret" has no data at all, just a presentational flip. So the concealment's thickness is zero: Duchamp's *infra-mince* (**P2**, digital readymade of Leonardo's method), the smallest conceivable difference, here the difference between a string and its mirror. The "Hold up a mirror" button flips the entire stage, which un-mirrors the note (double negative) while mirroring everything you were reading — so legibility is *conserved, never increased*. You can read the secret or the instructions, never both. That trade is the honest infrathin joke: the browser gives you nothing it was hiding, because it was hiding nothing.

It reads at two depths (**P7**): the casual visitor sees reversed handwriting and reaches for the "mirror" gag; the literate visitor recognises Leonardo, then the source-versus-render gap that y-a-v-a has worked for two decades — the same seam as *Silencio* (whitespace present in source, collapsed in view) and *La Disparition* (a glyph stripped before it lands). Here the seam is a mirror. Built as the smallest gesture that completes the thought (**P3**): one transform, one toggle, one per-visit tremor so no two loadings sit the same on the desk.

The reference it answers is **Leonardo's mirror writing** (the Codices), read through **Marcel Duchamp's *infra-mince*** and the net.art tradition of source-vs-render.
