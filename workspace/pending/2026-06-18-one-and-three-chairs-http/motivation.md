# One and Three Chairs (HTTP)

Joseph Kosuth's *One and Three Chairs* (1965) stages a single concept three ways: an actual wooden chair, a life-size photograph of it, and an enlarged dictionary definition of the word "chair." The piece asks which of the three, if any, is the art — object, image, or idea. This work answers Kosuth from inside the one medium that cannot complete his arrangement. A web page can deliver the photograph and the definition perfectly, but it can never deliver the chair. HTTP transmits representations, never things. So the "actual chair" panel here is a real, live `<chair>` element sitting in the DOM — an HTML tag the browser has no definition for, which it therefore renders as exactly nothing. The empty frame is not a missing asset; it is the honest maximum of the medium.

The mechanism *is* the argument (**P1**). The vacancy in the first panel is produced by the same logic Kosuth is interrogating: on the web there is no referent, only the sign. I did not draw a blank box to illustrate absence — I placed a genuine element the rendering engine cannot resolve, so the absence is structural, attested in the console (`getElementsByTagName('chair')` returns one element; visible count, zero). That unknown tag is a **digital readymade** (**P2**): the DOM's own inability to hold an object, framed and hung. The two remaining panels split along the chance/order axis (**P5**): the definition — language — is fixed and arrives intact, while the photograph is a procedurally generated line chair (a strict chair-grammar, random parameters) that is never the same picture twice and re-shoots on click. Of Kosuth's three terms, only the image proliferates; the object stays unreachable and the word stays still.

It is double-coded (**P7**) and built as small as the thought allows (**P3**). The casual viewer gets a dry gag — a museum triptych where the "real" one failed to load. The literate viewer gets the conceptual-art lineage and the net-native sting: Walter Benjamin worried the copy would dissolve the aura of the original; the web has gone further and dropped the original entirely, keeping only copies and captions. The tone is the cheerful cynic (**P9**): Kosuth could wheel the chair into the room; we can only ship its rumours, and we say so plainly.

It answers a named work — Kosuth, *One and Three Chairs*, 1965 — and sits in the conceptual/order half of the practice, alongside the readymade lineage of Duchamp. It could not survive as a print: a printed triptych would simply show three pictures, collapsing the very distinction the piece depends on. The vacancy only means something because a live browser is failing, in real time, to render an element that is really there.
