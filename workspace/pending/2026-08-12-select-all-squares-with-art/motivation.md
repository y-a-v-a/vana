# Select all squares with art

A CAPTCHA is a *Completely Automated Public Turing test to tell Computers and Humans Apart* — a machine that interrogates you to decide whether you are real. This work is a pixel-faithful digital readymade of Google's reCAPTCHA image challenge (P2), with one substitution: the prompt reads **"Select all squares with art,"** and the nine tiles are a Suprematist composition minted in your browser and cut into a 3×3 grid. Every composition contains Malevich's black square — the ur-object that first provoked "but is it art?" — so the challenge is at once trivially answerable (it is *all* art) and unanswerable (a black square is either everything or nothing). Press **VERIFY** and the grid silently fades and reshuffles into a new composition. It will do this forever. You cannot pass.

The **mechanism is the argument** (P1): the reCAPTCHA verify-loop is built to gate access, and here it gates *art*, exposing the whole authentication apparatus of the artworld — connoisseurs, jurors, certificates — as theatre that never resolves. The machine cannot let you through because it is asking a question it cannot answer itself. This inverts the Turing test into a reverse-Turing test about taste: you pass as human trivially; your judgement of "art" is what is being refused. It sits on the chance↔order axis (P5) — a strict Suprematist rule set thrown fresh by `Math.random` each attempt — and it points squarely at value and authenticity (P6): the endless, unwinnable gate is the market's authentication machine with its verdict withheld.

It answers a named web-native readymade — **reCAPTCHA** and Luis von Ahn's human-computation project, whose real purpose is to harvest your clicks to *train* machine vision — and a named artwork, **Malevich's *Black Square* (1915)**, via **Duchamp's readymade**. It also answers a prior y-a-v-a work: **"But is it art?" (2025)**, the page that simply says **YES**. This is the anti-YES — the machine that will never say yes, because affirmation would end the challenge and collapse the market it protects. The AI chapter is present too (P10): reCAPTCHA is the internet's great uncredited labelling engine, and the dry footer line — *"Every square you label teaches a machine what art is. It has not learned"* — interrogates that engine rather than merely using it.

Double-coded (P7): a casual viewer gets an instantly legible gag — a CAPTCHA you can never solve, asking about art. A literate viewer gets the reverse-Turing test, the Malevich lineage, and the market critique. The build is the smallest that completes the thought (P3): one canvas generator, nine tiles, a verify button that only ever reshuffles. Fully client-side — the real reCAPTCHA is a surveillance beacon, so the honest joke is that this one has no cookies, no trackers, and sends nothing anywhere; it "protects" nothing and stores nothing (P8).
