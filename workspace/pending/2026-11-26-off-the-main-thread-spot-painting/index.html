The idea, the grid and the signature are the artist's. Every spot is painted in a Web Worker: a separate thread, hired per CPU core, handed the canvas via transferControlToOffscreen(). After the handover the main thread is legally unable to touch it.

* Rule: no colour may repeat. The assistants share no memory and cannot see each other's spots.
