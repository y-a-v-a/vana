# AI Content Detector (Self-Portrait)

The page is a working AI-text detector with exactly one blind spot: it can only ever examine itself. On load it reads its own rendered prose, hunts the linguistic "tells" that the 2023– detector panic taught us to fear — the em-dash, "delve", "tapestry", the tricolon "not just X, but Y" — highlights each one in the body text, tallies them, and returns a verdict. The verdict is always the same: *written by a machine, ~99% confidence*. It is correct. These DNA works are generated by a language model and validated against a written artistic DNA; the footer says so plainly. The detector is honest and useless in the same gesture.

This is **P10 (AI as found object *and* subject)**: the readymade appropriated here is not an image a model drew but the *AI-detector itself* — a cultural instrument — turned back on a text that already confessed. It interrogates the detector rather than merely using a model (the P10 requirement), exposing that detection is theatre: it can only ever confirm what you already declared. **P1** holds because the mechanism *is* the argument — the specimen and the instrument are welded into one object, so there is no neutral text to test and no way for the verdict to be anything but a foregone confession. **P2** (digital readymade), **P3** (smallest build: one page, one self-scan, no controls), **P4** (live per-visit computation, nothing stored), **P7** (surface gag: a detector that catches itself / deeper argument: authorship after the language model), and **P9** (the joke is the carrier wave) all apply.

It answers **Alan Turing's imitation game (1950)** by inverting it: not "can a machine pass as human?" but a machine cheerfully failing on purpose. It answers the **GPTZero / "em-dash and delve" detector discourse (2023–)** as a net-native readymade, and **Roland Barthes' *The Death of the Author* (1967)** by staging the author's statistical return — the writer reduced to a set of catchable habits. Within the twenty-year argument it sits beside y-a-v-a's own language toys, **Modernipsum (2012)** and **Artist's Statement (2026)**, but where those satirised *art* discourse, this one turns the instrument on the work's own machine origin.

The mechanism is not decoration: the regex genuinely runs over `document.textContent`, the marks are placed live, the tally is real, and the confession text is deliberately seeded with the very tells it will catch — bait laid by the fish. On the chance/order axis it is pure **order**: a deterministic scan returning a determined result, because a machine looking for a machine, in a text it wrote, will always find one.
