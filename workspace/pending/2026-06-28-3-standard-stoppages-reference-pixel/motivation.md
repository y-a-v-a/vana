# 3 Standard Stoppages (Reference Pixel)

In 1913–14 Marcel Duchamp dropped a one-metre thread from a height of one metre onto a canvas, glued it down however it fell, and repeated this three times. He then cut wooden templates of the three crooked curves and kept them as *3 Standard Stoppages* — three new, equally valid units of length, each a metre that chance had bent into disagreement. It is the quietest possible attack on the metric system: the metre, humanity's agreed absolute since 1799, is shown to be a convention that gravity can overrule.

The web has its own Paris bureau. The CSS reference pixel is fixed by decree at **1 inch = 96 px** — an absolute that every layout engine on Earth trusts without question. This work drops three 96-pixel threads, lets each crumple by chance into a curve of the same true arc-length but a different straight-line reach, and then *adopts those three crooked inches as the page's rulers*. The page is asked the one measurement it should know cold — the width of its own window — and the three stoppages each answer with a different number. By the metre the window is, say, 1280 px, exactly, forever; by the stoppages it is three quarrelling decimals.

This enacts the **chance↔order axis (P5)** as literally as the catalogue allows: the order pole is the decreed pixel (96, exact, metric), the chance pole is the single fall that fixes each unit; the tension between them is not illustrated but *computed*, live, every time you resize. The mechanism **is** the argument (**P1**): the crumpled curve is not a picture of a ruler, it is the ruler — the same `unit` value that bends the SVG is the divisor that measures your viewport, so concept and execution are one object. It is a **digital readymade (P2)**: the appropriated object is not an image but a platform standard, the reference pixel, recontextualised as something gravity can dispute. And it points at **authenticity (P6)** sideways — each ruler is internally correct, so the only fiction is the standard itself.

It answers Duchamp's *3 Standard Stoppages* directly, and sits beside the catalogue's other measurement pieces — Bochner's honest viewport arrows, Brouwn's true reference-pixel distance, De Maria's real CSS kilometre — by inverting their shared premise: those measure the world with a trustworthy unit; this measures a trustworthy world (your exact pixel width) with units that chance has made untrustworthy. The canon is fixed once per visit and never drifts; only your window changes, so resizing re-measures the same fixed disagreement. No storage, no cookies, no network — the three standards live in memory and die on reload, which is the most faithful fate for a unit that was never standard. **CC BY-SA 4.0, y-a-v-a, after Marcel Duchamp.**
