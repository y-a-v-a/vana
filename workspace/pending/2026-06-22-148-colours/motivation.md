# 148 Colours

Gerhard Richter painted his colour charts — *1024 Colours* (1974), *256 Colours*, *4096 Colours* — by mixing primaries on a system and then arranging the squares by **chance**, explicitly to make painting "without composition" and to evict personal taste from the canvas. He wanted colour with no author behind the choice. This work answers him by pointing out that the web got there first: the colours already have a committee. The CSS Color Module Level 4 defines a fixed, named palette — `aliceblue`, `papayawhip`, `gainsboro`, `rebeccapurple` — chosen by a standards body, not an artist. The piece renders that palette as a Richter chart in which the artist mixed nothing, chose nothing, and did not even decide how many colours there are. The page counts them itself.

The mechanism *is* the argument (**P1, P3**). The script supplies only the 148 names — the readymade word-list of the spec (**P2**, a digital readymade in the Duchamp line). Each pixel is resolved live by the visitor's own browser via `style.backgroundColor` and read back out with `getComputedStyle`; the rendering engine, not the maker, supplies every colour, and the same names will quantize differently across engines and displays. The order is reseeded with a chance shuffle on every visit and on every press of *re-shuffle*, so no two loads compose the same chart and nothing is stored — the work is a behaviour, not a fixed image (**P4, P5**: the chance/order axis literalised, order = the alphabetical committee list, chance = the per-visit shuffle).

The nuance is in the names. Hovering reveals the absurd accidental poetry no painter would dare sign — `blanchedalmond`, `lightgoldenrodyellow`, `mistyrose` — and one swatch, `rebeccapurple`, is a memorial: added to the web in memory of a child. A grief sits inside a technical standard, and the artist authored none of it. That is the cheerful-cynic point about value and authorship (**P6, P9, P7**): on the web even taste has been outsourced to a spec, the colours are free and identical for everyone, and "composition without an author" is no longer an avant-garde aspiration but the default behaviour of `getComputedStyle`.

It could not be a print: a print would freeze one engine's quantization and one chance order, and would lose the live readout of the browser confessing each pixel back to you (**G1**). The named reference is Gerhard Richter's colour charts; the lineage runs back through Duchamp's readymade.
