Der Lauf der Dinge (transitionend)

After Fischli & Weiss, The Way Things Go (1987).

Each object moves only because the one before it finished: the browser's transitionend event is the nudge. No timeline drives it — it is a real causal chain. In the warehouse the suspense was will it work? Here the event cannot fail to fire, so the chain always completes. Mechanical reproduction kept the motion and threw away the doubt.

Positions and timings are re-thrown each visit and kept only in memory. Nothing is stored; reload runs a chain that has never run before and never will again.
