# Der Lauf der Dinge (transitionend)

Peter Fischli and David Weiss filmed *Der Lauf der Dinge* (*The Way Things Go*, 1987) as a thirty-minute chain reaction in a warehouse: a tyre rolls, a kettle tips, a flame creeps down a fuse, and each precarious event just barely triggers the next. Its entire charge is contingency — the maddening question *will the energy make the jump?* They shot take after failed take. This work moves that chain into the one place where causality is not a metaphor but a primitive: the browser's event loop. Each object here moves **only because the previous one finished**, using the `transitionend` event as the literal nudge. There is no master timeline, no `@keyframes` movie playing the whole sequence — link *N* begins because link *N−1*'s transition completed and fired an event. Break one listener and the whole apparatus halts, exactly as a missed collision stops the physical version.

That is the P1 argument: **concept is execution.** The causation is not depicted, it is the medium. A pre-baked animation would be a picture *of* a chain reaction; chaining through `transitionend` events is a chain reaction, running on the same causal machinery the DOM uses for everything else. It sits on the chance/order axis (P5): per-visit `Math.random` re-throws every position and duration so no two runs are pixel-identical (chance, held only in RAM, P4), while the deeper law is pure order — the browser's events **cannot fail to fire**. So the chain always completes. That is the cheerful-cynic point (P9): mechanical reproduction (Walter Benjamin) faithfully preserved the motion and quietly deleted the doubt. The web's version of *The Way Things Go* is the way things *always, reliably, boringly* go.

The named reference it answers is Fischli & Weiss, with Jean Tinguely's self-moving machines in the lineage — but where Tinguely's kinetics (and the catalogued *Acid Action Painting*) tend toward auto-destruction, this one is about transmission: energy handed politely from element to element until it runs out. It is materially distinct from every catalogued piece — none uses DOM event propagation as its substance, and the pointer never drives it (unlike *Bicho* or *Verb List*); the machine runs itself.

The mechanism is the message twice over. First, causality as event propagation. Second, the disappearance of suspense: a live counter tallies `transitionend` completions climbing to totality, and because the count can only ever reach the total, the readout is a small monument to guaranteed success — the opposite of the warehouse. Fully self-contained, no network, no storage, no cookies; reload discards this run forever and lets a chain that never existed run once. Licensed CC BY 4.0, attributing y-a-v-a and Fischli & Weiss.
