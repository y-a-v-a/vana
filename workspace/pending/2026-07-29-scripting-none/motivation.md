# Scripting: None

The entire y-a-v-a catalogue is built on live JavaScript mechanisms — render loops, observers, pointer deltas, crypto, timers. This work is the one that refuses to run. It is a gallery that is open only to a browser with scripting switched off, and closed to every browser that would execute code. And here is the twist that makes the mechanism the argument: **the page serves no JavaScript at all.** Nothing runs. The stylesheet alone decides whether the picture appears, by asking the browser a single question — `@media (scripting: none)` vs `@media (scripting: enabled)` (CSS Media Queries Level 5) — backed by the oldest web-native fallback for the unscripted visitor, the `<noscript>` tag. You are turned away not for anything you did, but for what your browser admitted it was *prepared* to do.

This is **P1** (concept *is* execution): the refusal is not illustrated by code, it is performed by the cascade — the medium's own capability query is the velvet rope. It is a **digital readymade** (**P2**): `@media (scripting)` and `<noscript>` are the web's built-in provisions for the scriptless reader, appropriated wholesale and promoted to be the whole gallery. It is the **smallest possible build** (**P3**) — zero JavaScript, a handful of CSS rules — and it is **double-coded** (**P7**): the casual visitor gets a dry gag ("disable JavaScript to see the art you came to see"), while the literate visitor reads an argument about complicity on the scripted, surveilling web — you are judged on disposition, not action.

It answers **JODI** (Joan Heemskerk & Dirk Paesmans), whose net.art treated the browser and its source as malfunctioning material you were never meant to see, and **Lee Lozano's *Dropout Piece*** (c. 1970), in which withdrawal from the system *is* the work: to see this piece you must yourself drop out of the running web. It sits on the chance/order axis at the pure-**order** pole — a deterministic, state-conditioned rule with no randomness — and points, per **P8**, at the ethics baked into delivery: a page that cannot track you because it runs nothing, moralising gently about the fact that most pages could.

Within the catalogue it is materially distinct. Other works detect the *network* (`navigator.onLine`), the *idle main thread* (`requestIdleCallback`), or *language* (`navigator.languages`); none conditions its own existence on whether scripting is enabled, and none makes its point by serving no script whatsoever. The nearest neighbour, *During the Connection the Gallery Will Be Closed*, toggles on connectivity via JavaScript; this one toggles on the browser's willingness to run JavaScript, using none — a different question asked by a different, script-free mechanism.

The wit (**P9**) is the carrier wave: the funniest possible outcome is a viewer opening dev-tools to find the script that rejected them, and finding nothing there at all. The rejection came from the stylesheet, and the stylesheet is telling the truth.
