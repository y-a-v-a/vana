# Endless Column (It Arrives Nowhere)

Constantin Brâncuși's *Coloana fără sfârșit* (1938) is a finite stack of identical rhomboid modules whose optical repetition makes the eye read an ending object as endless. This page is that sculpture rebuilt in the browser's two time-based materials — the Web Audio render loop and the canvas raster — where the illusion is not merely depicted but *performed*. Seven sine oscillators are spaced an octave apart; a single phase variable slides the whole stack upward and wraps each voice from the top back to the bottom, under a raised-cosine envelope that is silent at both ends. The result is a Shepard–Risset glissando: a tone that climbs forever and never actually gets higher. The same phase variable scrolls a column of bronze modules that likewise rise and never arrive.

The mechanism *is* the argument (**P1**). A print can draw Brâncuși's column but cannot make it ascend; a recording of a rising scale eventually has to loop, audibly. Only a live synthesis — oscillators whose frequencies wrap through a seamless spectral envelope — produces genuine endlessness, so the work could not exist as a static object (**G1**). Because one variable drives both ear and eye, concept and execution are a single object, not decoration bolted to an idea. It sits hard on the *order* pole of the chance↔order axis (**P5**): no entropy, pure deterministic rule, the same relentless climb in every browser — Brâncuși's rigid module as a loop.

It answers Brâncuși's *Endless Column* with the Shepard tone (Roger Shepard, 1964; elaborated by Jean-Claude Risset) — the auditory twin of the Penrose stair. It double-codes (**P7**): a casual visitor hears an unsettling, ever-rising tone and sees a column that won't stop; a literate one gets the finite-implies-infinite argument and, underneath it, the dry joke about every line that is supposed to only go up — the avant-garde's myth of perpetual progress, the market's price chart, the cult of ascent (**P6, P9**). Press *Let it rest* and the tone drops exactly to where it began; it arrives nowhere because there was never anywhere to arrive.

The build is the smallest that completes the thought (**P3**): no samples, no assets, no libraries — seven oscillators, one canvas, one phase. It is live, not fixed (**P4**); each session is its own unrepeatable climb. Fully self-contained and client-side: no network, no cookies, no storage, nothing sent (**G4**). `prefers-reduced-motion` freezes the visual stack while the ascent continues in sound.
