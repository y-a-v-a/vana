# Je signe (===)

A signature is drawn once, when the page loads, and minted as a JavaScript `Symbol` held in a closure — written to no cookie, no storage, no server. Below it sits the signature *spelled out as plain text*, offered for the taking. You can copy that text to the last character. Then forge it: the page builds `Symbol(text)` from exactly the string it just handed you and tests `forgery === original`. The answer is always **false**. Press the other button and it fetches the *registered* copy, `Symbol.for(text)` — the edition, the reproduction pulled from the global registry — and that too is not the original. The ledger confirms the cruelty plainly: text reproduced exactly, *yes*; forgeries that passed, *0*.

**The mechanism is the argument (P1).** In ECMAScript, every `Symbol()` is a unique value unequal to every other, even one constructed from an identical description; `Symbol.for()` returns a shared registry value that is still a different reference. So reference-identity in the language *is* Walter Benjamin's aura: the thing that cannot survive reproduction. The description string is the print — endlessly, perfectly copyable, and worthless as proof. Nothing here is decoration standing in for the idea; the `===` *is* the test of authenticity, and it fails by design. Reload and the original is destroyed, a different one signed — the aura is unique and perishable (P4).

**What it answers.** It takes Ben Vautier's Fluxus gesture *Je signe* — the artist whose signature, laid on anything, was the artwork — and asks what a signature even is once everything is bytes. It answers Benjamin (1935) directly: here is a work that is *nothing but* reproducible text, with its single non-reproducible atom isolated and shown to you (P2, P6). Behind it stands Duchamp's "R. Mutt" scrawled on a plumbing fixture: the signature as the whole of the readymade.

**Double-coded (P7), dry (P9).** The casual visitor gets a clean gag — *you copied it perfectly and it's still a fake*. The literate visitor gets the art-historical argument about aura and the signature; the net-native reader gets a precise interrogation of a language primitive, with the `Symbol()` / `Symbol.for()` pair staging hand versus edition. The signing itself is drawn with `crypto.getRandomValues` so no two hands are alike — chance in the stroke, order in the baseline (P5). The console attests what the page refuses to admit: `original === original` is the only `true` in the room.

**Ethics (P8).** Fully self-contained, client-side only, no external requests, no fonts, no tracking, no persistence. CC BY-SA 4.0, attributed to y-a-v-a with Ben Vautier, Walter Benjamin and Marcel Duchamp named.
