# Poor

The web-performance industry has a number for change and calls it a defect. **Cumulative Layout Shift** (CLS), the metric at the centre of Google's Core Web Vitals, measures how much a page's content jumps around after it loads; the lower the score, the "better" your page. Google's own bands are printed on the plate: *Good* ≤ 0.10, *Needs improvement* ≤ 0.25, *Poor* > 0.25. A well-behaved page holds perfectly still.

*Poor* takes the manifesto line literally — **"There is no 'art piece', only change"** — and points it straight at that metric. A column of blocks reflows forever, and the page installs a `PerformanceObserver` on `'layout-shift'` to watch itself misbehave. The same instrument the platform built to *penalise* movement becomes the meter of the work's vitality: the score climbs past 0.10 within a second or two and settles, permanently, on a large red **POOR**. The work proudly wears the failing grade the web hands it for being alive.

**The mechanism is the argument (P1).** The blocks live in normal flow, so when one changes height, every block beneath it genuinely jumps — these are real layout-shift entries, not a simulation of one. The number on the plate is not decoration bolted onto a picture; it *is* the picture's misconduct, read back from the browser's own audit. The composition is powered by both engines on the chance/order axis (P5): a strict grid of ruled bars (order) jolted by `Math.random` heights (chance). It is live behaviour rather than a fixed artifact (P4), and double-coded (P7) — a casual viewer sees coloured bars twitching under a big "POOR"; a literate one recognises a Core Web Vitals audit turned inside out.

The cruellest joke is reserved for `prefers-reduced-motion` (P9). Honour that request and the blocks stop, no shift is recorded, the score stays 0.000, and the browser finally rates the work **GOOD** — because to the web, a thing is only *good* once it has stopped changing, which is to say once it is a corpse or a print. This answers y-a-v-a's own **Panta Rhei (Read-Only)** (2026), the inverse piece that froze the pixels to prove time still passed; here the pixels never stop, and the platform's reward for stillness is exposed as an epitaph.

It answers the **W3C Layout Instability API / Google Core Web Vitals** as a web-native readymade, and nods to **Julio Le Parc**, whose kinetic *instabilité* made unpredictable movement the whole content of the work.
